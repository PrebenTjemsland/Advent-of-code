# Knowit 2024

Solutions to the **Knowit Julekalender 2024** puzzles — Knowit's internal Advent-of-Code-style puzzle event run each December.

Not affiliated with the official [Advent of Code](https://adventofcode.com/). Same flavour, different puzzles.

## Layout

Each `dayNN/` folder contains:
- `task.py` — the solution
- input files used by the puzzle (e.g. `blanket.txt`, `joe.txt`)

## Provenance

Migrated from the standalone `KnowitAOC` repository to consolidate puzzle solutions under one home.
